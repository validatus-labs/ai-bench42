# Four-phase benchmark: initial pilot scope

The program separates serving performance, general evaluation, tool use and
independent project development. The initial measured Kolibri work completed nine
short performance runs with 54 requests, a frozen general selection and a basic
tool pilot. These are different measures, not one combined quality score.

The general selection contains 32 distinct examples each from IFEval, MMLU-Pro,
BBH date understanding and BBH three-object logic: 128 unique examples. Three
repetitions yield 384 responses, not 384 independent questions. The completed
assessment and calibration comparison give the scores.

The tool pilot passed nine calls across only three unique simple BFCL cases.
SWE-bench patch evaluation was blocked by an unqualified execution environment;
it has no accuracy score. Early agent-container probes and prepared workspaces
were infrastructure checks, not completed coding trials. Later coding reports
record the actual attempts separately.

Failed setup and request-parameter attempts were retained. Exact source snapshots,
dataset selections, scorers and request accounting were checked privately.
Hardware and operational identifiers are withheld; short-prompt throughput is
therefore not offered as a portable hardware comparison.
