# First bootstrap validation: partial success

The first native bootstrap test used a 101-file working-tree package. It was a
test snapshot, not a newly approved coding freeze. Transfer/staging hashes matched;
repeat staging preserved files. Sixty-six regression tests passed with package
installation, GPU deployment and inference mocked. Real source preparation was
also repeated without changing its indexed bytes, permissions or timestamps.

Complete installation remained BLOCKED. Existing maintenance files disagreed
with new templates; working model, browser and health installations lacked new managed
registration; model boot policy differed. Missing metadata was not treated as
proof that the software was absent. Inspection and verification correctly
refused to overwrite the existing installation.

The review also found premature ownership registration and unconfigured experiment
inputs. A real complete install plus unchanged repeat was not established.
Mocked regressions and repeated source preparation must not be presented as
fresh-machine deployment or a live model/browser canary. A later explicit
existing-installation adoption addressed the migration separately.
