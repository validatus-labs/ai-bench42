# What the independent coding attempts established

Kolibri wrote code, ran tests and used real browser tools. None of the reviewed
independent attempts completed the full safe multilingual email parser. The
latest completed attempt passed 21 supplied tests, ten own tests and 24/27
supplemental probes, yet left important components disconnected from the API.

The earlier unchanged-file loop was real, but later attempts without that loop
also failed completion. Transport and session faults affected earlier runs;
the clean latest run ended naturally without time, request, tool, token or
context exhaustion. A single infrastructure explanation does not fit all runs.

Visible tests covered too little to establish integrated behavior. Independent
review exposed MIME, safe output, resource and reporting gaps beyond what a
passing small test suite could show. The separate Codex repair must not count
as Kolibri success.

The evidence supports testing supervised increments and stronger completion
checks. It does not prove an inherent inability to build parsers, a universal
configuration cure, a calibration fault or superiority of another model.
The subsequently authorized guided trial is a separate assisted experiment.
