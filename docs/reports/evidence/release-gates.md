# Release readiness versus completed benchmark

The readiness review separated repeatable infrastructure from experiment success.
At its preparation checkpoint, 202 native regressions passed and source/budget
selection was unified. Packaging/repeated configuration checks preserved expected
files. None of this supplied qualified SWE execution, a current isolated visible
worker or reviewed Gold/reference scoring automatically.

The README's source-data downloads were found. Another download would not solve
the missing target-label mapping, conversation split or independent annotation
review. Source labels and approved development data are not interchangeable with
held-out Gold. Missing scoring remained NOT_EVALUATED.

Later continuations did run Phase 4, but did not pass the full coding challenge.
They are recorded in the coding reports, not retroactively added to the earlier
infrastructure decision. The separate Codex-assisted repair is not an independent
Kolibri success. Historical infrastructure blockers, later readiness and final
candidate failures describe different moments and scopes.
