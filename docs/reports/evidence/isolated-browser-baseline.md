# An independently checked isolated browser baseline

A new Git-free Brave assignment was prepared without candidate solutions,
reference code, Gold, conversations or shared Git objects. C01–C07, API, visible
tests and non-tool budgets were preserved. Overall coding readiness remained
BLOCKED because inference attachment, visible session and data/evaluator gates
were separate requirements.

The bounded browser qualification demonstrated successful reads from the four
then-approved documentation origins, service-worker blocking, active renderer
sandboxing and denial of direct IPv4, IPv6, DNS and host-file access. A restricted
documentation broker validated destinations and redirects. Eleven local policy
tests passed; an independent reviewer repeated native file/network negatives
and checked archive contents. Repeated preparation preserved 31 indexed files.

The broker verified upstream TLS and fulfilled responses through Playwright;
this was not end-to-end browser TLS. Redirects retained the original browser URL,
which limited relative-link semantics. Read-only live system libraries remained
dependencies, so the boundary was not a fully immutable VM image.

An isolated Kilo backend connected MCP, but coordinator tool calls alone did not
prove isolated model-to-tool operation. Later C00 work tested that missing link.
Earlier coordinator failures were retained rather than relabelled successful.
