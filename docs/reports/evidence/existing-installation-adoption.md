# Adopting an existing installation without reinstalling

An authorized migration registered the existing calibrated Kolibri, native
Brave/MCP, health and maintenance setup without moving environments or weights.
Existing maintenance schedules and model boot policy were preserved. Historical
browser metadata remained intact; a separate fresh proof qualified the installed
browser version instead of rewriting old evidence.

Thirteen adoption and 16 portable regressions passed natively, with installation
and GPU operations mocked. Separately, seven real browser/MCP calls checked
interaction and sandbox diagnostics. Initial adoption succeeded; explicit repeat
and ordinary all-component repeat reported unchanged state with no model requests.
Registry bytes, modes and timestamps and selected existing files were preserved.

This closed existing-host registration gaps. It did not prove fresh-machine
installation, qualify a versioned automatic updater, renew isolated worker C00
or start coding. A later health-only refresh introduced 30-day history with its
own receipts. Detailed operational schedules, service identities, machine
inventory and original locations are withheld.
