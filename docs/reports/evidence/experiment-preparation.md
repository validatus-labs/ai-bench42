# Preparing inputs without claiming experiment readiness

The prepared experiment reused monitoring and installed tools, imported the
approved fixed 12-pair TRAIN bundle and pinned public evaluation data. Repeating
configuration generation preserved bytes, modes and timestamps. Sixty native
regressions passed. Overall readiness remained BLOCKED; no new quality or coding
result was generated by preparation.

The new general adapter used a fuller lm-eval protocol, including few-shot
templates. It was not equivalent to the historical LightEval fixed selections;
older scores could not qualify it. A BFCL checker passed positive/negative probes
without inference. Synthetic held-out adapter tests established implementation
behavior, not human Gold or independent evaluator approval.

TRAIN approval covered local worker disclosure, not TEST, EVAL or Gold. Annotation
offsets referred to authoritative annotation text, which differed from four
original source files; no raw-mail byte equivalence was invented. Remaining
gates were a qualified SWE execution/patch handoff, a configuration-bound isolated
visible Kilo worker and reviewed held-out reference/Gold evaluation.
